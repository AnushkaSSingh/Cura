# Cura Product Support Documentation

## Customer Orders

Customers can view their order status through the support system.

Possible order statuses include:

- Processing
- Shipped
- Delayed
- Delivered
- Cancelled

## Delivery

The support system can check:

- Order status
- Expected delivery date
- Actual delivery date
- Order amount

If an order is delayed, the support system should provide the verified status to the customer.

## Payments

Payment records can contain:

- Payment ID
- Order ID
- Payment amount
- Payment status
- Payment date

Multiple payments associated with the same order and amount may indicate a duplicate charge.

## Support Tickets

Previous customer support interactions can be used to understand the customer's history and avoid asking them to repeat information.

## Automated Actions

The prototype supports automated investigation of:

- Delayed orders
- Duplicate payments

Issues that cannot be verified should be sent to a human support agent.
